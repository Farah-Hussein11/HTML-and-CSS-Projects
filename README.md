# HTML-and-CSS-Projects

## 🌟 Features Implemented

### 1. Portfolio Native Highlights
* **Fixed Global Navigation System:** Sticky navigation panel built utilizing persistent screen position styling, color tokens, and custom highlight transformation rules.
* **Dual-Column Fluid Framework:** Balanced viewport containers utilizing strict dimension limits (`height: 350px`) alongside responsive layout configurations.
* **Filtered Visual Assets:** Custom centered showcase images enhanced via CSS filter operations (`hue-rotate`, `saturate`) and geometric properties (`border-radius: 25px`).
* **Interactive Overlays:** Smooth opacity-transition cards built to reveal title elements on user mouse movements.
* **Dynamic Video Hero Canvas:** Full-viewport, automated looping video interface operating under muted configurations for modern backgrounds.
* **Tabular Data Layouts:** Perfectly aligned technical data matrix tables built using isolated border structures, distinct cell spacing pad metrics, and bold header row fills.

### 2. Bootstrap Integration Project
Alongside this native portfolio code, this repository hosts our **Bootstrap Framework Project**. The bootstrap assignment utilizes responsive mobile-first component classes including:
* Fluid containers and layout columns (`.container`, `.row`, `.col-*`).
* Built-in navigation modules and theme utility modifiers.
* Pre-styled utility cards to streamline development without heavy custom styling sheets.
